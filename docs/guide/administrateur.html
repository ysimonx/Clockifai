Administrateur de l’installation

Administrer le serveur

Vous hébergez Clockifai (chez un hébergeur ou sur un serveur interne). Vous administrez le serveur et les comptes, pas le travail des équipes : les rôles et les règles d’une entreprise se règlent dans l’application, par son propriétaire.

Trois niveaux

Installation
Un serveur, administré par vous. Il peut accueillir plusieurs entreprises (workspaces), totalement cloisonnées.
Workspace
Une entreprise : propriétaire, administrateurs, managers, membres. Géré dans l’application.
Équipe
Un chef d’équipe pour un groupe de personnes, à l’intérieur d’un workspace.

Il n’y a pas de « super-administrateur » dans l’application : au-dessus des workspaces, vous travaillez avec Supabase Studio et le fichier de paramétrage du serveur.

Supabase Studio

La console d’administration du serveur est livrée avec Clockifai. Elle est accessible sur une adresse séparée (le domaine Supabase de l’installation) et protégée par un identifiant et un mot de passe (DASHBOARD_USERNAME, DASHBOARD_PASSWORD). Changez ce mot de passe dès l’installation.

Les comptes

La rubrique Authentication de Studio liste tous les comptes de l’installation, quelle que soit leur entreprise, avec leur date de création, leur dernière connexion et leur méthode de connexion. Vous pouvez :

  • créer un compte ou envoyer une invitation, utile pour le tout premier propriétaire d’une entreprise ; ensuite, les invitations se font dans l’application ;
  • depuis la fiche d’un compte : envoyer un lien de connexion, réinitialiser le mot de passe, bloquer ou supprimer le compte.

Ouvrir une nouvelle entreprise

  1. Le futur propriétaire crée son compte dans l’application (onglet Inscription, si les inscriptions sont ouvertes), ou vous lui envoyez une invitation depuis Studio.
  2. À l’inscription, il reçoit un workspace personnel « Espace de … » dont il est propriétaire ; il peut le renommer (Paramètres > Réglages du workspace) ou en créer un autre (Créer un workspace).
  3. Il invite ensuite ses équipes depuis la page Équipe (voir Inviter une personne).

Une fois les premiers comptes créés, fermez les inscriptions publiques (DISABLE_SIGNUP=true) : les invitations continuent de fonctionner.

Les données et la sécurité

L’éditeur de tables de Studio montre les tables de Clockifai : entreprises (workspaces), membres et rôles (workspace_members), projets, entrées de temps, absences, factures… En dépannage (propriétaire parti, compte bloqué), vous pouvez y corriger un rôle directement.

Chaque entreprise ne voit que ses données : le cloisonnement est appliqué par la base elle-même (sécurité au niveau des lignes), pas seulement par l’application.

Studio contourne ces protections : une modification faite ici s’applique sans contrôle. Préférez l’application pour tout ce qu’elle sait faire.

Requêtes SQL

L’éditeur SQL de Studio sert aux statistiques et aux contrôles : par exemple, le nombre de personnes et d’heures par entreprise. Le résultat s’exporte en CSV et les requêtes s’enregistrent pour être rejouées.

Paramétrage du serveur

Tout le paramétrage tient dans un seul fichier, deploy/.env, sur le serveur. Les réglages que vous toucherez le plus :

Principaux réglages de deploy/.env
RéglageRôle
SITE_URLAdresse de l’application (liens des emails).
APP_DOMAIN, SUPABASE_DOMAIN, SYNC_DOMAINLes trois noms de domaine du serveur ; HTTPS automatique.
DISABLE_SIGNUPtrue : inscriptions fermées, accès sur invitation seulement.
ENABLE_EMAIL_AUTOCONFIRMfalse : l’adresse email doit être confirmée à l’inscription.
SMTP_HOST, SMTP_USER…Envoi des emails (invitations, liens de connexion). Sans serveur d’email, l’invitation ne propose pas l’envoi : le lien affiché est à transmettre à la main.
JWT_EXPIRYDurée d’une session, en secondes.
BACKUP_KEEP_DAYS, BACKUP_HOURSauvegarde chaque nuit, gardée 14 jours par défaut.
JOBS_ENABLEDTâches automatiques, comme l’arrêt des chronomètres oubliés.

Exploitation et sauvegardes

Quelques commandes, depuis le dossier Clockifai sur le serveur :

make prod-up
Démarrer ou mettre à jour (Docker, HTTPS).
make migrate
Appliquer les évolutions de la base.
make backup
Sauvegarde immédiate, en plus de celle de chaque nuit.
make logs SERVICE=powersync
Journaux d’un service.
make psql
Console de la base.

Les sauvegardes sont écrites sur le serveur lui-même : copiez-les régulièrement ailleurs, et testez une restauration. La procédure complète (installation, mise à jour, sauvegarde, restauration, changement d’hébergeur, dépannage) est dans le guide d’exploitation livré avec Clockifai, docs/exploitation.md.

Les applications et ce guide

L’application web est servie par votre serveur, à l’adresse de l’installation. Les applications Mac, iPhone et Android, elles, sont construites pour une installation précise (ses adresses y sont intégrées) : pour votre propre installation, il faut les construire et les distribuer (TestFlight, Google Play, application Mac signée) avec vos adresses.

Ce guide est servi par votre serveur sous /guide/, à côté de l’application. Ses vidéos sont publiées à part ; tant qu’elles ne le sont pas, le guide reste lisible sans elles.
